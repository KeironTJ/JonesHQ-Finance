# Archived Deployment Notes

> **Historical reference only. Do not use this document to deploy, update,
> restore, or recover the production service.**

This file previously described the SQLite-era deployment process. That
procedure is obsolete and its commands and configuration examples have been
removed to prevent accidental use. Current production uses PostgreSQL, Redis,
the deployed `joneshq-finance` service, and the current installation path
documented in the runbook.

Use the authoritative [production runbook](../deployment/README.md) for all
current operational procedures, including deployment, database backup and
recovery, updates, and monitoring. The PostgreSQL rehearsal document is a
historical migration record, not an installation guide.
